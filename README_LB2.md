# Лабораторна робота № 2 – продовження ЛБ № 1

Вихідні маршрути ЛБ № 1 збережено. Додано редагування/видалення для трьох таблиць, дві SQL-статистики, одну з параметрами дати; окремі `routes/` та `controllers/`.

## Запуск
1. Встановити MySQL Server 8+; виконати `sql/01_schema.sql`, потім `sql/02_seed.sql` лише один раз.
2. `npm install`
3. Скопіювати `.env.example` до `.env` і вказати налаштування MySQL.
4. `npm start` і відкрити `http://localhost:3000`.

Маршрути редагування: `GET /types/:id/edit`, `GET /equipment/:id/edit`, `GET /plans/:id/edit`; збереження `POST` за цими адресами. Видалення: `POST /types/:id/delete`, `POST /equipment/:id/delete`, `POST /plans/:id/delete`.

Статистика: `/statistics/status` – групування за типами, `/statistics/period` – звіт за діапазоном дат (`POST` з параметрами `from`, `to`). Для операцій застосовано параметризовані SQL-запити. Зовнішні ключі `ON DELETE RESTRICT` забороняють видалення батьківських записів, на які посилаються дочірні.

Увага: у цьому середовищі немає підключення до вашого MySQL. Перевірте сценарії після запуску локально; у звіті наведено код і очікуваний вигляд, не вигадані скриншоти результатів запуску.
