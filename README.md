# Лабораторні роботи 1-2 - Облік планового ТО

## Запуск

1. Виконайте `sql/01_schema.sql`, `sql/02_seed.sql`, `sql/03_checks.sql` у MySQL.
2. Створіть `.env` за `.env.example` і вкажіть параметри своєї БД.
3. Виконайте `npm install` та `npm start`.
4. Відкрийте `http://localhost:3000`.

## ЛБ2

- Додавання, редагування та видалення даних у 3 таблицях.
- Для зовнішніх ключів є випадаючі списки.
- Підтвердження видалення і обмеження видалення зв'язаних записів.
- Статистика прострочених планів ТО.
- Статистика активності ТО за вибраний проміжок дат із датою формування.
- Структура MVC: `models`, `controllers`, `views`.
