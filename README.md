# Лабораторна робота №1 — MySQL

## Тема
«Інформаційна система «Електрична підстанція». Облік планового технічного обслуговування обладнання».

## Склад
- `sql/01_schema.sql` — створення БД і **рівно трьох** таблиць: `equipment_type`, `equipment`, `maintenance_plan`.
- `sql/02_seed.sql` — тестові дані: 5 типів, 7 одиниць обладнання, 10 планів.
- `sql/03_checks.sql` — перевірка кількості таблиць і зв'язків.
- `index.js` — Node.js / Express / `mysql2` з параметризованими SQL-запитами.
- `views/` — EJS-сторінки перегляду і додавання записів, детальна сторінка «Обладнання → Плани ТО».

## Встановлення та запуск
1. Встановіть MySQL Server 8.0+ і MySQL Workbench, Node.js (LTS).
2. У MySQL Workbench відкрийте і послідовно виконайте `sql/01_schema.sql`, `sql/02_seed.sql`, `sql/03_checks.sql`.
3. У папці проєкту виконайте `npm install`.
4. Створіть файл `.env` як копію `.env.example`. Впишіть **свій** пароль користувача MySQL у `DB_PASSWORD`. Ніколи не відправляйте `.env` викладачеві і не публікуйте його у GitHub.
5. Виконайте `npm start`.
6. Відкрийте в браузері `http://localhost:3000`.

## Перевірка вимог лабораторної
1. `http://localhost:3000/types` — перегляд / додавання типів обладнання.
2. `http://localhost:3000/equipment` — перегляд / додавання обладнання.
3. `http://localhost:3000/plans` — перегляд / додавання планів ТО.
4. Перехід «Переглянути» з реєстру обладнання — пов'язані плани конкретної одиниці обладнання.
5. У MySQL Workbench виконайте `sql/03_checks.sql` і переконайтеся, що таблиць рівно три, а кожна містить щонайменше п'ять записів.

## Для звіту
Зробіть **реальні скриншоти**: 3 екрани перегляду, 3 екрани після додавання, 1 екран із пов'язаними записами; також скриншот MySQL Workbench з трьома таблицями. Вставте їх у виділені жовтим місця Word-звіту. Скриншоти не формуються автоматично в цьому пакеті, оскільки для них треба запустити локальний сервер MySQL.
