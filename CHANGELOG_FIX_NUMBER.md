# Виправлення перевірки чисел

- Поля «Клас напруги», «Періодичність ТО» та «Тривалість» правильно приймають цілі та допустимі десяткові значення.
- Замість некоректної перевірки Number.isInteger(number * 10**places + 1e-8) використовується явна перевірка кількості знаків після крапки.
- Скорочено ім’я кореневої папки у ZIP для зменшення довжини шляхів у Windows.
